What is this file?

This file is the central configuration for the application.

Instead of writing values like:

DATABASE_URL = "postgresql://...."

inside every file,

we store them in

.env.example

and load them here.

In production companies:

Docker injects environment variables.
Kubernetes ConfigMaps and Secrets inject them.
AWS Secrets Manager or Parameter Store may provide sensitive values.

Keeping configuration separate from code makes applications easier to deploy across development, testing, and production environments.

================================================================================
                 Interview Questions
===================================================================================                 
Q1. Why use environment variables?

Answer:

To separate configuration from application code.

Examples include:

Database password
Redis URL
API keys
AWS credentials
Ports

This avoids hardcoding sensitive or environment-specific values.

Q2. What is pydantic-settings?

It loads environment variables into strongly typed Python objects with validation, making configuration easier to manage and less error-prone.

Q3. Why shouldn't secrets be hardcoded?

Because source code is often stored in Git repositories.

Production systems use:

AWS Secrets Manager
HashiCorp Vault
Kubernetes Secrets

instead of embedding secrets in code.

📚 Understanding this file

This file creates the database connection layer.

FastAPI
    │
    ▼
database.py
    │
    ▼
SQLAlchemy Engine
    │
    ▼
PostgreSQL

create_engine()
engine = create_engine(settings.DATABASE_URL)

This creates a connection engine to PostgreSQL.

Think of it as opening the highway to the database.

SessionLocal
SessionLocal = sessionmaker(...)

Every API request gets its own database session.

Example:

User A  ── Session A
User B  ── Session B
User C  ── Session C

This is important for handling multiple users safely.

Base
Base = declarative_base()

Every database model will inherit from Base.

For example, later we'll write:

class User(Base):
    ...

This tells SQLAlchemy to create a database table for the model.

get_db()
def get_db():

This is a FastAPI dependency.

It:

Opens a database session.
Makes it available to the request.
Automatically closes it when the request finishes.

This prevents connection leaks.

🧠 Interview Questions
Q1. What is SQLAlchemy?
A Python ORM (Object Relational Mapper) that lets you work with database tables using Python classes instead of writing SQL for every operation.

Q2. What is an ORM?

An ORM maps Python objects to database tables.

Example:

user.name = "Noor"

instead of:

INSERT INTO users(name)
VALUES('Noor');
Q3. Why do we use sessionmaker?
It creates a new, isolated database session for each request,
ensuring transactions are handled safely and connections are properly managed.
